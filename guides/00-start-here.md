# 从这里开始：失业应对操作台

> 本页给准备失业、刚失业、不确定资格的人使用。先按事实分流，再办理。**每个「完成」都要求有凭证，不以点过按钮为完成。**更新核验：2026-10-08。

## 第0步：三分钟定位自己的状态

先把答案记在纸上，不要公开发完整个人资料。

| 问题 | 选项 | 下一步 |
|---|---|---|
| 公司已经通知解除劳动合同？ | 是 / 否 / 协商中 | 协商中先看 [劳动补偿SOP](../playbooks/01-labor-exit.md)，不要代公司编离职原因 |
| 失业保险最后参保地或户籍地？ | 北京 / 上海 / 广州 / 其他 / 不清楚 | 北京、上海、广州看专属指南；其他城市到当地人社核对 |
| 失业保险累计缴费满一年？ | 是 / 否 / 不清楚 | 不是就先核对参保记录，不要自动把自己判断为符合资格 |
| 是否非本人意愿中断就业？ | 是 / 否 / 存在争议 | 让经办机构依据实情核定；如单位记录有误，先走信息更正 |
| 医保是否正在享受待遇？ | 正常 / 已中断 / 不知道 | 不知道就先查待遇状态，不先做缴费承诺 |
| 近期可用生活费？ | <3个月 / 3—6个月 / >6个月 | 少于3个月优先现金流与合法快速回款；有缓冲再评估转型 |

## 第1步：离职当天完成这张表

| 检查事项 | 是否完成 | 凭证 | 卡住找谁 |
|---|---|---|---|
| 解除形式/原因 | [ ] | 公司书面方案或实际沟通记录 | 公司HR、人社12333 |
| 工资、奖金和补偿明细 | [ ] | 计算清单与协议 | HR、劳动法律服务 |
| 付款日期 | [ ] | 协议/转账回单 | HR、必要时劳动仲裁 |
| 离职证明 | [ ] | 个人合法持有的文件 | 用人单位、人社 |
| 社保停缴月及减员原因 | [ ] | 社保个人查询结果 | 社保经办机构 |
| 个人资料合法留存 | [ ] | 个人劳动材料目录 | 公司HR或官方个人查询平台 |

> 看到「N+1」不要直接签。N、N+1、2N不是三个任选价格，见 [补偿核对](../playbooks/01-labor-exit.md)。

## 第2步：失业后的前72小时

**第1天：**保存上面6项；如有异议，用书面话术要求公司更正。**产出：**一页未解决问题清单。

**第2天：**查询个人失业保险缴费、就业登记、减员原因，在官方入口提交/尝试提交失业金申请。**产出：**受理编号、审核截图或明确的阻碍原因（仅自己保存）。

**第3天：**查询医保待遇状态和等待期，确认是否可在领取失业金期间由基金承担职工医保费；制作未来13周的家庭现金表。**产出：**医保接续日期及第一周的现金流预案。

**不要：**向陌生网友上传身份证/社保卡正反面；付费购买“保证领金”“挂靠社保”；为了解决社保焦虑随便办个体户；把未到账的离职补偿当作已到账现金。

## 第3步：按你真正的目标进入专项SOP

| 我现在的目标 | 直接进入 | 做完应拿到什么 |
|---|---|---|
| 公司要裁我，谈钱 | [离职与补偿](../playbooks/01-labor-exit.md) | 补偿核对表、协议风险清单 |
| 已离职，领失业金 | [失业金与医保](../playbooks/02-benefits-insurance.md) | 核定结果/补正清单、医保待遇确认 |
| 身上有债，工资没了 | [13周现金流](../playbooks/03-cashflow-rescue.md) | 第一周现金安全边界、账单表 |
| 投简历没人回 | [求职漏斗](../playbooks/04-job-search.md) | 30个目标岗位、3张项目证据卡 |
| 想接单、做自媒体 | [从第一笔付费开始](../playbooks/05-first-customer.md) | 服务说明、访谈记录、第一笔验证 |
| 家里有孩子，半年没收入 | [长期家庭与城市计划](../playbooks/06-family-reset.md) | 分工表、城市对照表和下次复盘日 |

## 第4步：确认是否真正完成

办事类：保存官方办理编号、经办名称、日期、待遇起始月份。政策核对类：记下政策生效日期、你属于哪类人群、该怎么适用。现金流类：写出下一个低于零的周及应对方案。求职类：有记录、有复盘、有下一轮修改。商业类：**到手回款**才记为现金收入，预约咨询不等于成交。

如遇到医疗、债务、劳动纠纷等影响生计的紧急事件，先找对应专业机构、银行或官方经办，线上资料不能替代个案办理。
