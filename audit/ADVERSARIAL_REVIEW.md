# 对抗式审核：失业自救指南 v2

核验日：2026-10-08。此文件公开记录不适用情形、纠错和仍待进一步核查的风险。**对抗式审核不等于由有执业资格的律师、社保经办人员或保险机构进行个案审核。**

| 攻击方式 / 反例 | 原先风险 | 当前修复 | 剩余边界 |
|---|---|---|---|
| 用户主动辞职，以为人人都能领失业金 | 把普遍条件说成必然 | 问解除原因、累计缴费、登记、既往领金，给拒绝原因处理路径 | 经办机构确认个案资格 |
| 京籍参保经验套到非京籍 | 错误注册主体/缴费 | 北京个人参保明确核户籍、实际身份；提醒不能靠空壳个体户挂靠 | 有雇工/真实经营需属地确认 |
| 上海医保断缴一定要等6个月 | 错过3个月正常接续免等待期 | 分职工/居民参保身份、待遇中断时间、原享受状态 | 具体待遇起算及跨省衔接需经办确认 |
| 用N+1自动报价全部裁员 | 补偿计算法错误 | 拆分第40条解除、协商、违法解除 | 证据与个案法律判断 |
| 把月房贷和到期债务都扣一次 | 现金流安全期低估 | 13周现金流模板逐项现金记账，避免重复计数 | 现金预测仍有估算误差 |
| 把尚未批准失业金算进现金 | 现金流高估 | 基准情景只记确定回款，待批入乐观情景 | 到账时间仍可能推迟 |
| 漏看医保，先做高成本社保挂靠 | 损失/违法风险 | 失业金医保→待遇确认→合法参保再缴费 | 医保等待期个人差异 |
| “开顺风车来赚钱”被理解为无限量营运 | 违反合乘规定、保险争议 | 明确合乘不是经营性客运，需核车牌、次数、路由、保险 | 地方政策、保单条款不断变化 |

| 自媒体粉丝涨了却没有商业收入 | 盲目消耗救命现金 | 10次访谈→试单→收款→交付，禁止拿观看量代替成交 | 无成功收益保证 |
| 用户传工资流水到公共Issue | 隐私和商业秘密风险 | 隐私警示、提供本地表格和匿名协作规则 | 本地设备和浏览器安全由用户管理 |
| 城市页面过期，金额悄悄变化 | 错误政策指引 | 源记录带核验日期、城市文件单独维护、贡献模板要求生效日期 | 本仓库不自动确认实时有效性 |

## 维护者的审核次序

1. 查政策的**适用对象**（户籍、参保地、工作状态、退休时间等）。
2. 查实施和更新日期，确认未被新规定替代。
3. 按例外情形攻击结论（主动辞职、跨省参保、医保断缴超过3个月、未实际到账、离职前谈判）。
4. 公式边界测试：0现金、0支出、收入≥支出、负数输入、超大数。
5. 测试用户从读到执行全程是否有：入口→材料→动作→结果→失败处理。
6. 审核隐私和公开社区投稿，不接受任何个人真实财务或医疗材料。

## 尚未解决的边界

- 全国所有城市政策并未全部逐条核验；只列北京、上海、广州已整理内容。
- 页面是操作路线图，不是实时行政审批查询服务。
- 不采集用户真实个人资料，不自动申请失业金、不代表法律机构。
- 无法保证面试、兼职、创业获得收入。
- 官方网页有时改版，失效链接需要社区提交Issue更新。

**发布结论：**可作为公开、带有明确限制的自助办事路线图；专业争议仍需要向当地官方和合格专业人士核实。
