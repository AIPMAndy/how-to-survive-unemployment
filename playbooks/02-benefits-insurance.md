# SOP 02｜失业金、医保、社保、公积金四件事

**先后顺序：**确认离职减员事实 → 确认失业保险资格 → 官方申请 → 查询医保是否已接续 → 再核实养老及公积金。不要把“领取失业金”当作“所有个人都自动具备资格”。

## 1. 带着这5个问题先自查

- 最近的失业保险参保地、户籍地分别在哪里？跨省转移有没有完成？
- 累计缴纳失业保险是否满一年？以前是否领取过失业保险金？
- 解除是用人单位发起、协商解除，还是本人主动辞职？登记是否如实？
- 是否已经办理失业登记？是否愿意按规定接受就业服务？
- 社保卡金融功能、个人账户能否收款？

**结果：**以上五个答案都记录清楚，再进入申请。任何一项不明，先查原单位减员及个人参保记录，不建议用猜测填表。

## 2. 北京办理：从入口到回执

1. 打开 [北京人社局](https://rsj.beijing.gov.cn/) 或北京人社服务渠道，搜索「失业保险金申领」。
2. 按提示以社保卡或法定允许的身份证明及银行卡办理，完成失业求职登记要求。
3. 核对累计缴费、解除原因、银行账户和联系信息；申请时**不要提交假材料**。
4. 保存受理编号或申领记录。北京现行办法规定一般在5个工作日内告知审核结果。
5. 获批后确认核定金额、应领月份、发放月份；领取期间职工医保费按规定由失业保险基金缴纳。
6. 出现重新就业等法定停发情况时，北京现行办法要求在情形发生之日起20个工作日内主动办理停领手续。

**审核失败：**问经办机构具体原因；减员登记或缴费记录错误请按要求更正；如争议较大，索取具体政策依据与法定救济途径。

官方：[北京申领发放实施办法](https://rsj.beijing.gov.cn/xxgk/2024zcwj/202412/t20241227_3974931.html) / [北京申领问答](https://rsj.beijing.gov.cn/xxgk/2024zcjd/202412/t20241227_3974959.html)。

## 3. 上海办理：从入口到回执

1. 先查最后失业保险参保地或户籍地是否在上海；符合申领地条件并完成用人单位退工后，按规定办理失业登记。
2. 打开「随申办」搜索「失业保险金申领」，按界面提交；也可到区就业促进中心或街镇社区事务受理中心。
3. 线下通常使用有效身份证件/社保卡和指定银行的个人实名借记卡或存折；具体代发银行见官方问答。
4. 上海2026年新办法规定一般在受理之日起5个工作日内完成审核，符合条件者一般从受理次月按月发放，通常是次月15日前后。
5. 保存申请记录、核定月份、发放账户；2026年8月16日后的新申领，不用每三个月重复申请。旧周期有过渡。
6. 重新就业等法定情形应当主动停止领取；错误多领取可能被追缴。

**拒绝或一直未到账：**保留办理编号→确认单位退工、失业登记、银行卡、跨省缴费数据→联系经办机构。不要找“包过”的付费中介。

官方：[上海2026实施办法](https://rsj.sh.gov.cn/tshbx_17729/20260812/t0035_1443067.html) / [政策问答](https://rsj.sh.gov.cn/tzcjd_17352_17352/20260812/t0035_1443066.html)。

**广州：**先在“粤省事”或“粤就业”办失业登记，再在“粤省事”、“广东人社”APP 或广东人社网上服务平台申领；受理后7个工作日内审核，审批通过后次月15日前发放，领取次月起每月做资格核对。金额、期限、医保与公积金见 [广州政策](../guides/guangzhou.md)。

## 4. 医保不能照搬“断了6个月就没了”

**请将这句话问清楚：**“我在【日期】停止享受【职工/居民】医保待遇，现在【准备领取失业金/以灵活就业参保/以其他身份参保】，下一次医保待遇从哪天开始，有等待期和例外吗？”

上海2025年职工医保实施细则：灵活就业参保一般存在6个月等待期；原本正常享受职工或居民医保待遇者，在待遇中断后的3个月内按规定转为灵活就业参加职工医保，符合条件的**不受这项等待期限制**。上海居民医保还有另套2026年规定，不可混用。

**完成标准：**你记录了经办答复、参保方式、应缴金额、待遇起始日期。遇到慢病、正在治疗等情况应优先直接找医保经办明确连续性。

## 5. 社保、公积金：先核资格再付款

- **北京：**个人灵活就业参保官方公开条件包含北京市户籍等要求；注册个体户不意味着非京籍自动有个人参保资格。到属地经办核实实际经营与参保身份。
- **上海：**符合条件的在沪灵活就业外地户籍人员可以参保，自己承担费用；当年缴费基数和比例必须按官方最新口径确认。
- **广州：**外省户籍灵活就业人员可凭广东就业登记证明在广州参加职工养老和职工医保；非广州户籍离职、公积金封存满半年且无异地缴存可销户提取。见 [广州政策](../guides/guangzhou.md)。
- **北京非京籍公积金：**符合条件的离职封存满半年且没有异地继续缴存，可申请销户提取；其他情况不套用。
- **跨省：**不要重复投保或误认转移接续已经完成；分别向转出地、转入地查状态。
