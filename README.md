## 这个仓库解决什么问题？

前段时间，有位朋友从 100 公里外专门来找我吃饭。他在公司待了 6 年，知道自己要拿 N+1，却不知道离开以后怎么办。

我平时会帮很多社招朋友做求职咨询。失业后的问题，往往不止找工作：补偿怎么谈、医保是否会断、失业金在哪领、什么时候可以转去做自己的生意？

所以做了这份指南。**所有建议都尽量落到具体行动，政策附原文，读者可以自己核对。**

### 先做这 7 件事

1. **没离职：** 确认解除原因，核对 N / N+1 / 2N，**别把不符合事实的“主动辞职”签成定案**。
2. **当天：** 核对离职证明、补偿金额、付款日期、欠付工资、奖金及社保停缴月份。
3. **尽快：** 核对失业保险资格，按属地渠道申请；并无全国统一“离职后第 7 天必须申请”的法定死线。
4. **当天查：** 看医保待遇是否正常，尤其核对领取失业金期间是否由失业保险基金缴纳职工医保。
5. **做笔账：** 近期可用资金 − 近期必须偿还债务，再除以家庭每月**必要净支出**。
6. **下周：** 找 5 位了解你工作能力的前同事/同行，告诉他们你想找的岗位和城市。
7. **两周后：** 看岗位匹配率、投递回复率、面试推进率；没收入时，不要盲目借钱创业。

**🔎 如果现在只做一件事：打开 [`index.html`](index.html)，按阶段勾完前三项。**

### 如何本地使用？

下载仓库并**双击 `index.html`** 即可。无 Node、无依赖、无服务器，离线可用。任务勾选保存在浏览器 `localStorage`，没有用户账号或上传；现金流数字只在当前页面计算，不会发送到外部。

若要修改数据并重建页面，安装 Python 3.9+ 后运行：

```bash
python3 build.py
python3 -m unittest discover -s tests -v
node tests/calc.test.js  # 开发者可选；验证纯算法边界
```

项目架构：`data/guide.json` 是任务与政策结构化数据源；`assets/app.css`、`assets/app.js`、`assets/calc.js` 是 UI 与纯计算源文件；`build.py` 生成**自包含** `index.html` 和 **19份可直接手机阅读**的离线HTML版指南。提交时将生成的文件一并提交，读者无需安装工具。浏览器使用中所有个人数字留在本地。

## 两个最容易踩的坑

**“裁员就是 N+1 吗？”** 不一定。法律上的 N、代通知金及违法解除赔偿属于不同法律情形。具体依据 [《劳动合同法》](https://rsj.gz.gov.cn/zcfg/flfg/content/post_7993969.html)。

**“北京和上海，医保断缴都要等 6 个月吗？”** 不能一概而论。特别是上海 2025 年实施细则规定了灵活就业参保的 6 个月一般等待期，**也规定原本正常享受职工或居民医保、在中断 3 个月内转为灵活就业职工医保可免等待期**的情形。参见 [上海市职工基本医疗保险办法实施细则](https://www.shanghai.gov.cn/gwk/search/content/6173c838284f43c3b4d8c8d4513364ed)。

## 常见问题 FAQ

### 失业了第一件事做什么？

先别急着签字。核对补偿、失业金和医保，再算手上的现金还能覆盖几个月。具体顺序看上面的 [先做这 7 件事](#先做这-7-件事)。

### 被裁员后怎么办，补偿一定是 N+1 吗？

不一定。法律上的 N、代通知金和违法解除赔偿是不同的情形。先确认解除原因，别把不符合事实的“主动辞职”签成定案。详见 [离职当天与 N/2N](playbooks/01-labor-exit.html)。

### 失业金怎么领，有没有“第 7 天”的死线？

先核对失业保险资格，再按属地渠道申请。全国并没有统一的“离职后第 7 天必须申请”的法定死线。北京、上海、广州的规定分别看 [北京政策](guides/beijing.md)、[上海政策](guides/shanghai.md) 和 [广州政策](guides/guangzhou.md)。

### 失业以后医保会断吗？

要当天查医保待遇是否正常，尤其要核对领取失业金期间是否由失业保险基金缴纳职工医保。断缴后要不要等待期，各地规定不同，上海的例外情形见上面“两个最容易踩的坑”。

### 手上的钱还能撑几个月，怎么算？

用近期可用资金减去近期必须偿还的债务，再除以家庭每月必要净支出。网站里有现金流计算器和 13 周现金流表，数字只在你的浏览器里计算，不会上传。

### 这份手册收费吗？政策多久核验一次？

免费，不用登录，下载后双击 `index.html` 离线也能用。北京、上海政策最后核验 2026-10-08，广州 2026-10-30，办理时以当地官方最新政策为准。
